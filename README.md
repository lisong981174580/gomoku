# 弈五子 · Gomoku

一款无需安装、打开即玩的网页版五子棋。

## 功能

- 人机对战：悠闲、认真、高手三档难度
- 本地双人对战
- 自选黑白棋、悔棋、重新开始
- 胜负战绩和偏好自动保存在浏览器
- 深色模式、落子音效、手机与电脑自适应

## 本地运行

直接打开 `index.html`，或在目录中启动任意静态文件服务器：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 技术说明

原生 HTML、CSS 和 JavaScript 实现，无第三方依赖。AI 使用棋型评分、攻防权重和候选点搜索。
